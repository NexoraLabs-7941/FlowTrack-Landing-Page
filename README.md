# FlowTrack Landing Page

Landing page del proyecto **FlowTrack**, desarrollada con **HTML, CSS y JavaScript**.  
Esta página tiene como objetivo presentar de forma clara la propuesta del sistema, sus principales beneficios y sus funcionalidades más importantes.

## Despliegue

La landing page se encuentra publicada en Netlify:

https://hilarious-babka-588afa.netlify.app/

## Descripción del proyecto

**FlowTrack** es una landing page orientada a mostrar una solución digital de forma visual, ordenada y accesible.  
El sitio incluye secciones informativas, imágenes del proyecto, diseño responsive y elementos interactivos básicos para mejorar la experiencia del usuario.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Netlify
- GitHub

## Archivos principales

- `index.html`: contiene la estructura principal de la landing page.
- `styles.css`: contiene los estilos visuales del sitio web.
- `script.js`: contiene las funciones e interacciones de la página.
- `assets/`: carpeta donde se almacenan las imágenes y recursos visuales.

## Funcionalidades principales

- Presentación visual del proyecto.
- Diseño responsive para distintos dispositivos.
- Secciones informativas sobre la solución.
- Uso de imágenes y recursos gráficos.
- Interacciones básicas mediante JavaScript.

## Cómo visualizar el proyecto

Puedes visualizar el proyecto de dos formas:

1. Abriendo el archivo `index.html` directamente en un navegador.
2. Accediendo al despliegue publicado en Netlify.
